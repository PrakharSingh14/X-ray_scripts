# X-ray_scripts

Scripts for solar X-ray data analysis.

| Folder | What it does |
|---|---|
| [`Xray_Data_Download/`](Xray_Data_Download/) | Download Chandrayaan-2 **XSM** and Aditya-L1 **SoLEXS** day files from ISRO's PRADAN portal |
| [`SoLEXS_HELIOS_joint_fitting_demo/`](SoLEXS_HELIOS_joint_fitting_demo/) | Aditya-L1 **SoLEXS + HEL1OS** spectra and joint spectral fitting of a solar flare (example notebooks, data included) |
| [`resources/`](resources/) | Reference papers on SoLEXS and HEL1OS, for reading alongside the scripts |

Each folder has its own README with setup and usage instructions.
